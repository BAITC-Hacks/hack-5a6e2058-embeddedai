## Проверяемость и пределы

- AI не получает сырые таблицы и не создаёт внешние атрибуты клиентов. Платный
  сервис нужен только для дополнительного вопроса на естественном языке.
- Назначения — эвристические гипотезы; разметки нет, accuracy не заявляется.
- Устойчивость к выбранным сценариям не является вероятностью правильности.
- Вопросы AI не охватывают произвольный SQL, даты и условия по суммам; неверное
  понимание вопроса возможно. План виден пользователю; неподдерживаемые сочетания
  параметров и потеря выбранной группы отклоняются.
- Заметки очереди локальны в браузере, не являются общей базой расследований;
  для передачи коллегам есть CSV. Выбор ограничен 20 узлами.
- Офлайн HTML содержит весь набор и открывается без сервера, но не заменяет
  интерактивную графовую схему. Для графа используется веб-приложение.
- Браузер и тесты запускаются на Linux. Windows/macOS инструкции подготовлены,
  но выполнение на этих ОС не заявляется. CI по решению владельца отключён.

Публикацию на платформе выполняет участник самостоятельно.
