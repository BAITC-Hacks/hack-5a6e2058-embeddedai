# Материалы сдачи

Название: **Граф денег — EmbeddedAi**

Описание:

Инструмент для AML-аналитика: загружает три Parquet-файла, строит направленную сеть
переводов, назначает объяснимые роли каждому узлу, выделяет сообщества и формирует
очередь проверки с числовыми обоснованиями. В интерфейсе — поиск точного gid,
фильтры, граф со стрелками, карточка потоков и ограничений, просмотр сообществ,
скачивание nodes_roles.csv, clusters.csv и top_nodes.csv.

На официальном наборе обработаны все 2 248 узлов, включая 19 изолятов. Учтены
444 узла на границе обхода и неполные входящие seed. Расчёт выполняется локально
без GPU и платных API; есть единая команда проверки и 17 автоматических тестов.
Роли — гипотезы для аналитика, не вывод о виновности.
