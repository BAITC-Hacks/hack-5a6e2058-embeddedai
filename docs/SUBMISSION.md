# Материалы сдачи

Название: **Граф денег — EmbeddedAi**. Приложение **0.8.0**, правила **2.2**.

## Описание для платформы

Локальный инструмент для AML-аналитика: три Parquet → объяснимые роли,
сообщества, приоритет проверки и три CSV заданной схемы. Единственная команда
`uv run --frozen --no-dev python analyze.py --data ./data/data --out ./artifacts`
выполняет весь расчёт и возвращает JSON с результатом, путями, количеством строк
и SHA-256. Для расчёта не нужны Node.js, браузер, GPU, API-ключи или платные сервисы.

Официальный результат охватывает все 2248 узлов, включая 19 изолятов:
88 сообществ и TOP 50. Все 444 узла на границе обхода учитываются с ограничением
наблюдаемости. Шесть ролей назначаются открытыми правилами; карточки показывают
метрики, пороги, альтернативы, поправку наблюдаемости и вклад в приоритет.
Рейтинг сочетает структуру и денежный объём. На предоставленном наборе
посредничество рассчитывается точно. Int64 gid сохраняются без округления.

Интерфейс показывает направленный граф, точный поиск gid, сообщества, полную
очередь проверки, хронологию и пути. Дополнительные признаки: FIFO-совместимость
входов и выходов через 1–2 дня, всплески относительно собственной медианы,
поступления от нескольких плательщиков за день, повторные малые суммы и
необычные профили относительно своего колена. Для каждого показаны правило,
размер выборки и ограничения. Повторные суммы — повод проверить гипотезу
дробления; операции ниже порога выгрузки не восстанавливаются.

Есть короткие возвратные контуры, повторяемые звенья A→B→C, статическое удаление
TOP-N с сопоставлением degree и случайных выборок, чувствительность рейтинга,
ролей и сообществ. Аналитик скачивает CSV, карточки с происхождением данных и
PNG графа. CLI создаёт автономный HTML-отчёт, работающий без сервера и интернета.
Доступны светлая, тёмная и системная темы, сохранение расчёта и локальные заметки.

AI-аналитик расположен над графом. Он учитывает открытый узел, выбранную группу,
фильтры, очередь и продолжение диалога; выбирает ограниченные проверки по графу
и отвечает со ссылками на реальные узлы. В OpenAI передаются вопрос, контекст,
краткая история и запрошенные производные факты; исходные Parquet целиком и
локальные заметки не отправляются. Без ключа остальные функции работают полностью.
На публичном демо платный AI защищён отдельным кодом доступа.

Роли и сообщества — гипотезы для проверки, не утверждения о виновности.
Эталонной разметки нет, поэтому accuracy не заявляется. Наблюдаемый маршрут
не доказывает движение одних и тех же денег, удаление узлов не является
рекомендацией блокировать счета. Текущий предел — 10 000 узлов; план перехода
к миллиону описан отдельно, такая масштабируемость не заявляется реализованной.

Инструкции охватывают Windows, macOS и Linux; фактически проверки выполнены
на Linux. Lockfiles закрепляют зависимости. Независимый скрипт сверяет все
выгрузки и исходные Parquet. Полная команда проверки включает Python-тесты,
lint, типы, production build, API и браузерные сценарии. CI отключён по решению
владельца. Подробный протокол — [VALIDATION_08.md](VALIDATION_08.md).

  в `manifest.json` с SHA-256 каждого файла.

35 слабосвязных компонент; оборот **365 890 012,01 KZT**.
Публичный VPS содержит только синтетику. Полный архив предназначен для закрытой
передачи жюри. Сдачу через платформу выполняет участник.
