# Материалы сдачи

Название: **Граф денег — EmbeddedAi**

Описание:

Инструмент для AML-аналитика: три Parquet-файла → объяснимые роли, сообщества,
приоритет проверки и три CSV точной схемы. Все 2248 узлов официального набора
сохранены, включая 19 изолятов; 444 узла на границе обхода не объявляются
конечными по отсутствию исходящих переводов.

Доказательная карточка показывает пороги роли, вклад в рейтинг, дневные потоки,
направленные пути от seed, короткие возвратные контуры и повторяемые звенья.
Обзор сообществ раскрывается до конкретных участников. Справка узла и PNG графа
скачиваются. Неопределённость данных и следующие проверки видны аналитику.

Рейтинг учитывает структуру и наблюдаемый денежный объём. 12 сценариев изменения
весов показывают чувствительность TOP 20; моделирование удаления N узлов сравнивает
приоритет с degree и 20 случайными выборками. Все эксперименты пересчитываются
на загруженных данных, без заранее подготовленных ответов.

Расчёт работает локально на CPU, без LLM, GPU и платных API. Есть общая команда
проверки: lint, типы, вычислительные/API-тесты, production build и браузерные
сценарии. Фактические замеры — docs/VALIDATION.md. Роли — гипотезы для проверки,
не вывод о виновности; при отсутствии истинной разметки accuracy не заявляется.
