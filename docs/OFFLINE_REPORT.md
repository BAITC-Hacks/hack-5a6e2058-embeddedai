# Автономный HTML-отчёт

Та же команда, которая формирует три обязательных CSV, автоматически сохраняет
`report.html` в каталоге результата:

```bash
uv run --frozen --no-dev python analyze.py --data ./data/data --out ./artifacts
```

После успешного завершения откройте `artifacts/report.html` двойным щелчком в
проводнике Windows, Finder macOS или файловом менеджере Linux. Отчёт работает
через `file://`: Node.js, веб-сервер, API-ключ и интернет для просмотра не нужны.
В веб-интерфейсе отчёт доступен через «Выгрузить результат → Офлайн-отчёт HTML».
Чтобы ссылки на CSV работали, оставьте три скачанных CSV рядом с HTML.

Инструкции установки uv и вариант через обычный pip — в [RUNNING.md](RUNNING.md).
Отчёт создаётся и при передаче трёх отдельных файлов через `--nodes`, `--edges`,
`--transactions`; дополнительный аргумент или отдельный запуск не требуется.

## Что содержится в отчёте

- Число узлов, направленных рёбер, транзакций, seed, сообществ, изолятов и узлов
  на границе наблюдения; период и оборот, распределение ролей.
- TOP-50 с объяснениями и переходом к строке конкретного узла.
- Все узлы с точными строковыми gid, ролями, поддержкой правила, приоритетом,
  входящими и исходящими объёмами, степенями, сообществом и основанием роли.
  Доступны поиск, фильтр роли и сортировка по приоритету, потокам или роли.
- Сообщества: внутренний оборот, внешние вход и выход, seed, ведущие узлы и
  структурная гипотеза.
- Формальные условия ролей с фактическими порогами текущего запуска, порядок
  разрешения пересечений, ограничения наблюдения и чувствительность TOP-20 к
  изменению весов приоритета.
- Полная конфигурация правил и SHA-256 исходных Parquet-файлов.
- Светлая, тёмная и системная темы. Тема сохраняется, если браузер разрешает
  localStorage для локальных файлов; запрет хранилища не мешает просмотру.

Список узлов и все объяснения уже находятся в HTML. При отключённом JavaScript
работают чтение и ссылки; поиск, сортировка и ручное переключение темы недоступны.
Можно использовать стандартный поиск браузера и печать в PDF.

## Проверяемость и ограничения

Отчёт использует уже вычисленный результат и не запускает повторный анализ.
Он не меняет схемы и байты обязательных `nodes_roles.csv`, `clusters.csv`,
`top_nodes.csv`. CSV, JSON и HTML публикуются одной завершённой генерацией;
при ошибке формирования HTML прежний каталог результата сохраняется.

В JSON-ответ CLI добавлено отдельное поле `report_html` с абсолютным `path` и
`sha256`. Поле `exports` по-прежнему описывает именно три обязательных CSV.
Хеш HTML относится к конкретному запуску: внутри отчёта записано фактическое
время расчёта, поэтому повторный запуск может дать другой хеш HTML при одинаковых
CSV. SHA-256 конфигурации считается от показанного JSON с сортировкой ключей,
отступом 2 пробела, кодировкой UTF-8 и без завершающего переноса строки.

Все тексты экранируются. Политика Content Security Policy запрещает сетевые
загрузки, а встроенные CSS и JavaScript разрешаются только по их SHA-256.
Идентификаторы не преобразуются в JavaScript Number. В HTML нет API-ключей,
запросов к AI и внешних шрифтов/CDN.

Это снимок текущей выгрузки, а не интерактивная карта всех транзакций. Проверка
устойчивости ролей и кластеров выполняется отдельно в веб-интерфейсе; здесь
показана базовая чувствительность приоритета к весам. Роли, приоритеты и
структурные гипотезы не являются вероятностью преступления или выводом о
виновности. Большой оборот может повторно учитывать одни средства в цепочке.

Сам HTML содержит идентификаторы и результаты анализа исходной выборки. Для
публичного демо используйте только синтетический набор, как и для веб-приложения.

## Выполненная проверка

В Chromium на Linux файл открыт по `file://` при отключённой сети. Проверены
поиск точного gid, фильтр роли, пустое состояние, сортировка объёмов, переход из
TOP к скрытой фильтром строке, переключение и сохранение темы, ширина 390 px и
чтение с отключённым JavaScript. Сетевых запросов и ошибок браузера не было.

Отдельный замер формирования HTML с 10 000 строками на подготовленном результате:
0,205 с, размер около 10 MB. Это замер только сериализации отчёта, а не полного
анализа такого графа; скорость открытия файла зависит от браузера и компьютера.
Автоматические тесты проверяют экранирование недоверенного текста, CSP-хеши,
полноту узлов и ссылок, неизменность исходного результата, CLI-манифест и
сохранение предыдущей генерации при ошибке HTML.
