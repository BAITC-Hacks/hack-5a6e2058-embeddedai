# AI-ассистент: проверяемые ответы по графу

Это необязательная функция приложения 0.6. Основной анализ и обязательные
артефакты воспроизводятся без ключей, интернета и платных сервисов.

## Как устроен ответ

1. Пользователь отправляет вопрос и, при необходимости, выбирает до 20 узлов.
2. OpenAI Responses API интерпретирует вопрос одним вызовом `query_graph`.
   Используются strict JSON schema, принудительный выбор функции и запрет
   параллельных вызовов. Модель по умолчанию — `gpt-4.1-mini-2025-04-14`.
3. Сервер проверяет структуру, диапазоны и идентификаторы: модель не может
   сослаться на gid вне вопроса/выбранного контекста или отсутствующий в графе.
4. Детерминированный Python-исполнитель обходит текущий граф, вычисляет факты,
   формирует текст и ссылки. Модель не пишет числовой ответ.
5. Интерфейс показывает ответ, выбранную операцию, ограничения и реальные карточки.

Контракт OpenAI: [function calling](https://developers.openai.com/api/docs/guides/function-calling).
Промпт и схема открыты в `assistant_prompts.py`, проверка и обращение к API —
в `assistant.py`, вычисления — в `graph_query.py`. Нет исполнения SQL/Python
из ответа модели, свободных URL, цепочек агентов или автоматического повтора
платных вызовов. Запросы выполняются только по нажатию «Спросить».

## Поддерживаемые вопросы

| Операция | Пример |
|---|---|
| Общие получатели | «Кто получает деньги от всех выбранных?» |
| Общие плательщики | «Кто переводит этим узлам?» |
| Несколько шагов | «Кто получает от этих узлов за два шага?» |
| Карточки | «Почему эти узлы получили такие роли?» |
| Рейтинг | «Покажи пять консолидаторов с максимальным входящим объёмом» |
| Направленный путь | «Есть ли путь от gid A до gid B?» — замените A/B точными gid |
| Сообщество | «В каких сообществах находятся выбранные узлы?» |
| Возвратные пути | «Есть ли циклы у выбранного узла?» |

По умолчанию поиск общих контрагентов использует прямые связи и требует
совпадения для всех выбранных источников. Косвенные связи — только по явному
запросу, до четырёх шагов. В каждом пути показаны наблюдаемые рёбра. Их суммы
не складываются в «дошедшую сумму»: связь в графе не доказывает движение
одних и тех же денег. Роли остаются гипотезами для проверки.

Запросы вне графа, изменения данных, атрибуты клиентов, произвольная фильтрация
по дате и другие отсутствующие в схеме операции возвращают уточнение.
Модель может неверно понять формулировку; проверьте показанную операцию и ссылки.
Отсутствие найденного пути относится только к заданной глубине и текущей выборке.

## Данные, ключ и доступ

В API уходят только вопрос и список выбранных gid; полного графа и скрытого
обогащения внешними источниками нет. Не вписывайте чувствительные сведения
в вопрос. `store: false` отключает сохранение объекта Responses для дальнейшего
получения; это не обещание отсутствия обработки/служебного хранения у провайдера.
Приложение не сохраняет историю чата и не пишет вопросы или ключи в журнал.
Заметки очереди остаются в localStorage браузера и в API не отправляются.

Переменные `OPENAI_API_KEY` / `OPENAI_API_KEY_FILE`, `OPENAI_MODEL` и
`MONEY_GRAPH_ASSISTANT_TOKEN` описаны в README. При смене переменных перезапустите
сервер. Файлы `.env` автоматически не загружаются. Установка нового SDK не нужна:
HTTPS-запрос выполняется стандартной библиотекой Python.

Публичный сервер защищает платный endpoint отдельным кодом. Без него граф,
отчёты и остальные API доступны как раньше. Неверный код даёт HTTP 401;
неверный gid/вопрос — 422; параллельный запрос или лимит 60/час — 429;
отсутствие ключа/доступа/баланса провайдера — 503; тайм-аут — 504.
Лимит общий на процесс и сбрасывается при перезапуске; для нескольких реплик
нужен общий шлюз лимитов. Прекращение ожидания в браузере не гарантирует отмену
уже начатого платного запроса на сервере.

Обычные автоматические тесты используют подмену OpenAI и не расходуют токены.
Результаты отдельных настоящих запросов фиксируются в отчёте проверки релиза.
