# Демонстрация: пять минут

Сценарий для приложения **0.4.0**, правил **2.1**. Актуальные замеры и выполненные
проверки — [VALIDATION_04.md](VALIDATION_04.md); условия ролей — [METHODOLOGY.md](METHODOLOGY.md).

## Подготовка

Для показа официального набора из приватного репозитория:

```bash
./scripts/start.sh --data data/data --port 3010
```

Откройте `http://127.0.0.1:3010`. Убедитесь, что выбран нужный расчёт: 2248 узлов,
3119 связей, 4840 транзакций, 88 сообществ. Если браузер восстановил другую
сохранённую загрузку, загрузите три файла из `data/data/` через интерфейс.

Открытая ссылка https://cca8f159.nip.io показывает явно обозначенную синтетику:
80 узлов и 95 связей. Официальные данные демонстрируйте локально либо в закрытой
сессии жюри; не загружайте их в публичное демо для подготовки презентации.

Не заучивайте старые позиции и роли gid из версии 2.0: точное посредничество
в 2.1 изменило часть рейтинга. Выбирайте примеры из текущего расчёта. Заранее
откройте нужные файлы CSV и найдите один seed-изолят и один узел уровня 4 через
фильтры. Алгоритм не содержит заранее выбранных ответов.

## Сценарий

1. **0:00–0:35 — задача и воспроизведение.** Загрузить три официальных файла,
   показать 2248 узлов и фактическое время расчёта. «От 81 seed к очереди проверки
   всей наблюдаемой сети». В карточке методики указать точный расчёт посредничества
   для этого объёма и отсутствие платных внешних зависимостей.
2. **0:35–1:30 — первый приоритет.** Открыть текущий первый узел TOP. Сопоставить
   evidence с потоками и порогами роли. Раскрыть «Вклад в приоритет и правила»:
   показать денежный объём, поддержку до/после поправки и диапазон места при
   изменении весов. Подчеркнуть, что поддержка правила — не вероятность виновности.
3. **1:30–2:25 — доказательства.** Нажать «Пути, циклы и хронология» прямо под
   evidence. Показать путь от seed с суммами на каждом звене, дневные вход/выход
   и точные суммы по датам. Объяснить разницу между наблюдаемым путём и
   недоказанным движением тех же денег; отсутствие короткого цикла не исключает
   длинных контуров.
4. **2:25–3:15 — произвольный gid жюри.** Вставить полный идентификатор без
   округления. Показать окружение со стрелками и суммы по нажатию на связь,
   перейти к сообществу. Затем выбрать заранее найденный узел уровня 4:
   отсутствие выхода не означает удержание; следующий запрос — продолжение обхода.
   При вопросе об изолятах показать сохранённый seed без рёбер.
5. **3:15–4:15 — ценность приоритета.** «Проверки» → смоделировать удаление пяти
   узлов. Сравнить с degree и 20 случайными выборками. Объяснить разрыв связности
   между оставшимися вершинами; оборот затронутых рёбер не называть процентом
   остановленных денег. Не скрывать, если простая стратегия лучше по одной метрике.
6. **4:15–5:00 — передача аналитику.** Скачать справку узла с SHA-256 источников
   и три обязательных CSV. Показать одну команду расчёта и `./scripts/verify.sh`,
   диаграмму и ограничения. Уточнить: нет истинной разметки, обогащения клиента,
   автоматической блокировки или платного API в основном сценарии.

## Контроль перед показом

- Проверить маркировку и размер выбранного набора, затем обновить страницу:
  ссылка должна восстановить тот же расчёт.
- Не показывать старые CSV рядом с карточкой правил 2.1; при необходимости
  пересчитать `uv run --frozen money-graph analyze --data data/data --out artifacts`.
- После неизвестного gid исправить значение или выбрать узел из TOP. После
  временной ошибки начальной загрузки нажать «Повторить загрузку».
- Если времени мало, сохранить произвольный поиск, объяснение роли, границу
  наблюдения и скачивание CSV; дополнительные эксперименты показать по запросу.

Сдачу через платформу выполняет участник. Название и описание подготовлены в
[SUBMISSION.md](SUBMISSION.md).
