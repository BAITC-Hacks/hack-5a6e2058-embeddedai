# Демонстрация: пять минут

1. **0:00–0:40 — задача.** «Из списка seed и четырёх уровней переводов строим
   объяснимую очередь проверки. Не устанавливаем виновность по структуре графа».
2. **0:40–1:20 — воспроизведение.** Загрузить три официальных файла, показать
   2 248 узлов и время расчёта. Показать команду CLI из README.
3. **1:20–2:20 — приоритет.** Открыть первый узел top-list. Объяснить его
   структурную роль, числа, вклад признаков и предупреждение о неполном входе.
4. **2:20–3:00 — граф.** Ввести произвольный gid жюри, показать соседей и стрелки,
   перейти к сообществу. ID не округляются в браузере.
5. **3:00–4:00 — ограничения.** Фильтр depth=4: отсутствие исходящих означает
   границу наблюдения, а не удержание денег. Изолированный seed остаётся в CSV.
6. **4:00–5:00 — артефакты.** Скачать три CSV, показать документированные правила,
   схему архитектуры и единую команду проверки. Отметить локальную работу без API.

Для публичной ссылки используется синтетический набор с отметкой в шапке.
Официальный набор показать локально или в закрытой сессии жюри. Подготовить
три примера из свежего расчёта: важный связующий узел, граница, изолированный seed.
Не зашивать ID этих примеров в вычислительную логику.
