# Устойчивость аналитических гипотез

Дополнительная проверка отвечает на вопрос: «Изменится ли вывод, если немного
изменить порог роли или настройки сообщества?» Она выполняется по запросу для уже
рассчитанного результата. Обязательный CLI, исходный приоритет, роли, cluster_id
и три CSV от неё не меняются. Повторных расчётов PageRank и betweenness нет.

Это **диагностика чувствительности**, а не accuracy, вероятность правильности,
оценка виновности или доказательство корректности исходных данных. Если перевод
не попал в выгрузку, перебор параметров его не восстановит.

## Роли: до 16 сценариев

Используются исходные признаки, процентили и та же функция `roles.classify`, что
в основном пайплайне. Для каждого сценария меняется один фактор; остальные
настройки сохраняются. Проверка показывает точные значения `changes`, число
изменившихся ролей и таблицу переходов `from_role → to_role`.

| Фактор | Изменение относительно исходного правила |
| --- | --- |
| Минимум seed-предков, плательщиков и получателей связующего узла | Каждый порог отдельно: ±20%, минимум один узел; нижняя граница 1 |
| Минимум получателей распределителя | ±20%, минимум один узел |
| Минимум плательщиков консолидатора | ±20%, минимум один узел |
| Процентиль посредничества связующего узла | ±5 процентных пунктов; с 0.90 до 0.85 / 0.95 |
| Интервал выход/вход для транзита | Полуширина ×0.75 / ×1.25 при неизменном центре; с [0.80; 1.20] до [0.85; 1.15] / [0.75; 1.25] |
| Максимум выход/вход для консолидатора | ±5 процентных пунктов; с 0.20 до 0.15 / 0.25 |

Округление целочисленных порогов использует Python `round`. Вырожденные варианты,
которые повторяют исходную настройку, пропускаются. Для нестандартного нулевого
интервала транзита расширение составляет до ±0.05; сузить такой интервал нельзя.
Пороги отношений ограничены допустимыми положительными значениями.

Доля неизменившихся ролей считается **только среди узлов с внешними
контрагентами**. Изоляты и узлы с одними самопереводами не создают искусственно
высокого согласия. У них `assessed=false`, `unchanged_fraction=null`.
Seed и граница сохраняют существующие ограничения наблюдаемости; проверка не
начинает назначать им запрещённые потоковые роли.

Для каждого gid возвращаются базовая роль, доля сценариев с той же ролью,
число появлений каждого варианта роли и конкретные сценарии изменения.
Отдельно выделен TOP‑20 исходного рейтинга. Значение 1 означает лишь, что этот
небольшой набор сценариев не изменил роль. Взаимодействия нескольких порогов
одновременно здесь не исследуются.

## Сообщества: восемь дополнительных разбиений

Строится та же взвешенная неориентированная проекция: сумма денежных переводов
между парой узлов, без самопереводов. Проверяются три seed
`random_seed`, `random_seed + 1`, `random_seed + 2` и три resolution
`0.8 × исходный`, `исходный`, `1.2 × исходный`. Совпадающая с исходным расчётом
пара исключена: остаётся восемь сравнений, а не девять с заведомо идеальным
повтором. Сохранённые исходные сообщества служат точкой сравнения.

Различаются три вида сценария:

- `seed`: меняется только порядок обхода Louvain;
- `resolution`: меняется только масштаб выделяемых сообществ;
- `resolution_and_seed`: меняются оба параметра.

Смена resolution выражает другой масштаб анализа, поэтому её эффект нельзя
целиком называть «случайной нестабильностью». Более высокий resolution обычно
выделяет более мелкие группы; порядок обхода также может влиять на результат.
См. [документацию NetworkX Louvain](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.louvain.louvain_communities.html).

Сравниваются составы групп, а не произвольные числовые cluster_id:

- **Adjusted Rand Index (ARI)** сравнивает всё разбиение с поправкой на случайное
  совпадение. 1 означает одинаковое разбиение с любыми номерами групп; значение
  около 0 — согласие на уровне случайной модели; отрицательные значения допустимы.
  Реализация использует таблицу сопряжённости за O(V), без зависимости от
  scikit-learn. Определение и свойства описаны в
  [документации adjusted_rand_score](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.adjusted_rand_score.html).
- **Jaccard окружения сообщества для TOP‑20**: размер пересечения / объединения
  старого и нового состава группы конкретного узла. Сам узел исключается из
  обоих множеств, чтобы не завышать оценку маленьких групп. Два пустых окружения
  считаются совпадающими; у узлов без внешних связей оценка отсутствует.

В обоих показателях изоляты исключены. Отчёт содержит число фактически
проверенных сценариев, все параметры и показатели каждого сценария.

## Время и ограничения

Поддерживается текущий предел приложения: 10 000 узлов / 50 000 рёбер. Это не
заявление о полной обработке миллионного графа. Для проверки сообществ выделен
бюджет 20 секунд, проверяемый **между** запусками Louvain. Один начатый запуск
выполняется полностью: это не жёсткий тайм-аут. При исчерпании бюджета возвращается
`status=limited`, предупреждение и только завершённые сценарии. Если внешних
рёбер нет, статус `not_applicable`, а показатели `null`, не фиктивные 100%.

23 сентября 2026 года на исходном наборе 2 248 узлов / 3 119 рёбер отдельная
диагностика заняла **1.913 с** на Linux, Python 3.12, Intel i5‑8250U. Выполнены
все 16 вариантов ролей и 8 вариантов Louvain. Это один локальный замер, без
времени исходного пайплайна и без обещания такой скорости на любом компьютере.

- В сравнении участвуют 2 229 активных узлов; 19 изолятов исключены.
- Минимальная доля сохранённых ролей — **94.48%**: уменьшение минимума
  плательщиков консолидатора с 3 до 2 меняет роли 123 узлов.
- При изменении только seed минимальный ARI равен **0.8780**.
- Минимальный ARI среди всех восьми вариантов — **0.7960**, при seed=44,
  resolution=1.2.

Эти измерения показывают реальные пограничные решения, но не выбирают «лучшее»
правило по отсутствующим эталонным меткам. Основные результаты сохранены.

## Проверяемость

`tests/test_robustness.py` проверяет независимость ARI от номеров групп,
отрицательный ARI на пересекающихся разбиениях, прямой перебор пар для всех
бинарных разбиений четырёх узлов, пограничные роли, исключение изолятов,
неизменность исходного результата, воспроизводимость, null вместо ложного
совпадения на пустом графе и честный частичный результат при лимите времени.

```bash
uv run --frozen pytest -q tests/test_robustness.py
```
