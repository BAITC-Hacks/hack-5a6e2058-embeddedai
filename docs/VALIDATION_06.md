## Автономный отчёт и диагностика

Chromium открыл `file://.../report.html` при блокировке всех сетевых запросов:
поиск полного gid, фильтр роли, сортировка, переход по ссылке на скрытую строку,
светлая/тёмная тема с сохранением, пустая выдача и ширина 390 px проверены.
Без JavaScript остаётся статическая таблица. Внешних запросов и ошибок консоли
не было. Генерация отдельного синтетического HTML для 10 000 строк — 0.205 с,
примерно 10 МБ; это замер рендеринга отчёта, не всего аналитического пайплайна.

Роли: 16 сценариев, минимум сохранённых назначений **94.48%** среди 2229 активных
узлов. Сообщества: восемь сценариев, минимум ARI **0.7960**, только смена seed —
минимум **0.8780**. 19 изолятов исключены из долей согласия. Диагностика отдельно
заняла **1.913 с**; исходный результат не изменился. [Подробности](ROBUSTNESS.md).

## Реальные обращения к OpenAI

Использован собственный серверный ключ, модель `gpt-4.1-mini-2025-04-14`.
Обычные автоматические тесты не используют этот ключ и не делают платных вызовов.
Три настоящих запроса на синтетическом графе:

| Вопрос | Наблюдаемый результат | Время / токены input+output |
|---|---|---|
| Кто собирает деньги с этих пятерых? | Три общих прямых получателя; 550000, 350000, 150000 KZT от выбранных пяти источников; по пять операций | 3.325 с / 913 |
| Пять консолидаторов с максимальной входящей суммой | В графе один подходящий узел: 210000 KZT; остальные четыре не выдуманы | 2.494 с / 857 |
| Есть ли циклы у выбранного узла? | Ноль найденных коротких циклов у указанного узла; ограничение поиска показано | 3.926 с / 849 |

Суммы, направления, число источников и ссылки проверены детерминированным
исполнителем по рёбрам графа. В API передавались вопрос и строковые gid,
без таблиц и заметок. Дополнительная первая проверка вызова функции потребовала
840 токенов. После этих измерений промпт дополнен правилами сохранения выбранной
группы и допустимых сочетаний фильтров; эти ограничения проверяются сервером.

## Скорость API

Отдельный TestClient-прогон официального набора: первый разбор/проверка сохранённого
JSON — 0.6053 с; после кеширования TOP — 0.0076 с, сообщества — 0.0063 с,
граф — 0.0222 с, отфильтрованная очередь — 0.0159 с. Повторная диагностика
устойчивости из кеша — 0.0082 с. Это локальные измерения без сетевой задержки.
При перезапуске проверенный начальный расчёт также сохраняется в кеше.
Изменение, замена и удаление JSON инвалидируют кеш; повреждённые/устаревшие
данные не выдаются за актуальные, что проверено отдельными тестами.
