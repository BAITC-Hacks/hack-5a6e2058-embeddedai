# Проверка версии 0.7.0

Дата: 23 сентября 2026. Правила анализа остаются 2.2.

## Изменение

AI-аналитик расположен над показателями, вне внутренних вкладок. Он получает
контекст карточки, выбранных узлов, общих фильтров и текущей страницы очереди
с сортировкой и поиском. Диалог имеет ограниченную серверную историю, привязанную
к конкретному расчёту. Модель выбирает последовательность проверок и объясняет
вычисленные результаты; ссылки проверяются сервером. Основной CLI остаётся автономным.

Модель — `gpt-5.4-mini-2026-03-17`, reasoning=low. Доступны шесть ограниченных
инструментов; пределы, приватность и API-контракт описаны в [ASSISTANT.md](ASSISTANT.md).

## Выполненные проверки

Команда:

```sh
uv run --frozen python scripts/verify.py
```

- Ruff lint и format, mypy: прошли.
- **386 Python-тестов**: прошли за 33,25 с.
- Установка frontend по lockfile, Biome, TypeScript и production build: прошли.
- Проверка собранного frontend, production API и CSV: прошла.
- **37 Playwright-сценариев**: прошли за 1,2 мин.
- После небольшого улучшения отображения выделений в AI-тексте повторно выполнены
  frontend check/build и 9 сценариев AI/прокрутки: прошли за 31,3 с.
- Те же **9 сценариев через публичный HTTPS**: прошли за 29,5 с.

Браузерные размеры: 1440×1080, 1366×768, 820×1180, 390×844. Проверены обе темы,
глобальное расположение AI, независимая вертикальная прокрутка, переходы к узлам,
выполнение действий только по нажатию, отмена, смена расчёта и устаревший диалог.

Сетевые ответы модели в автоматических тестах подменены. Проверены, в частности:

- последовательность поиска, анализа узлов и окончательного ответа;
- продолжение диалога по результату предыдущего вопроса;
- отличие выбранной группы, открытой карточки и видимой страницы очереди;
- запрет неподтверждённых ссылок и неизвестных действий;
- сохранение всей явно выбранной группы при первой относящейся к ней проверке;
- сохранение ссылок на промежуточные узлы путей, даже если кратких профилей больше 20;
- изоляция диалогов по run_id и отпечатку отчёта, истечение 30 минут, пределы памяти;
- лимит последовательности и платных вызовов, повтор инструмента, тайм-аут;
- ошибки ключа/провайдера, отсутствие раскрытия ключа и кода доступа;
- строгие схемы и воспроизведение контекста reasoning при `store: false`.

Существующие предупреждения pandas о вычислениях на крайних int64 и предупреждение
Starlette о будущем изменении тестового транспорта сохраняются; тесты проходят.

## Настоящие запросы OpenAI

Выполнены отдельные успешные проверки новой модели, вне автоматических тестов:

| Сценарий | Результат | Время |
|---|---|---:|
| Синтетика: выбрать три приоритетных узла | `find_nodes`, проверенные ссылки | 8,1 с |
| Продолжение: сравнить первых двух | `inspect_nodes(compare)`, правильные gid из истории | 9,1 с |
| Локальный браузер: объяснить роль открытого узла и следующий шаг | Две проверки `inspect_nodes`, 13 ссылок, без ошибок браузера | 13,0 с |
| Публичный браузер: выбрать два приоритетных узла | `find_nodes`, 16 ссылок, общий вопрос не ограничен карточкой | 6,9 с |
| Публичный браузер: сравнить их входящие суммы | `inspect_nodes`, продолжение того же диалога, 15 ссылок | 9,7 с |

Это функциональные примеры, а не оценка точности модели на всех формулировках.
Текст AI может ошибаться: детерминированные факты показаны отдельно. Проверка
существования и происхождения gid не доказывает каждое предложение модели.
