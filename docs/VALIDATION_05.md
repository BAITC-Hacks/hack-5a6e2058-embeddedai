Новые регрессии проверяют:

- выбор режима посредничества по активным узлам, опоры и нормировку полного графа;
- устойчивую точность PageRank и корректную поддержку пользовательских границ транзита;
- числовое evidence при наличии только самопереводов;
- проверку CSV/manifest и сохранение старых файлов при дефекте сериализации;
- необычные профили, малые/одинаковые когорты, строгую границу IQR и смену единиц сумм;
- денежные итоги около предельного допустимого оборота и обнаружение подмены на 0,1 KZT.

## Изменения результата и обоснование правил

На официальном наборе **роли всех 2248 узлов и состав/порядок TOP 20 сохранены**.
Уточнённые процентили и PageRank изменили ранги 678 остальных узлов, максимум на
16 позиций. Это устранение конкретных численных и ранговых искажений, не
заявление о росте accuracy: истинной разметки нет.

| Показатель | Результат |
|---|---:|
| Узлы / активные / seed | 2248 / 2229 / 81 |
| Рёбра / транзакции | 3119 / 4840 |
| Компоненты / изоляты | 35 / 19 |
| Граница depth=4 | 444 |
| Сообщества | 88 |
| Оборот KZT | 365890012,01 |
| coordinator / distributor / transit | 32 / 37 / 68 |
| consolidator / terminal / peripheral | 74 / 1034 / 1003 |
| Узлы с необычным профилем внутри колена | 230 |

Словарь и абсолютные пороги ролей не масштабируются автоматически по N.
Пересчитываются относительные метрики; равные положительные значения получают
0,5, а не искусственно высокий ранг в маленькой группе. Изоляты не включаются
в выборку опор. Профиль по колену — отдельное свидетельство, не поправка роли/TOP.
Детали формул и отказов от оценки: [METHODOLOGY.md](METHODOLOGY.md).

Дополнительный численный аудит обнаружил допустимый набор из 101 узла, 100 рёбер
и 100 переводов с оборотом 8,99×10¹³ KZT: несогласованные сумматоры расходились
на 0,015625 KZT. Итоги и сводки переведены на `math.fsum`; абсолютный допуск
0,01 KZT сохранён, относительного допуска нет. Реальный Parquet-набор теперь
проходит анализ и экспорт, изменение результата на 0,1 KZT всё ещё обнаруживается.
Эта коррекция не изменила официальные CSV относительно уже рассчитанных правил 2.2.
